# PyBOOT: Python Bootcamp

**Author:** Federica Bianco

## Overview

This bootcamp material was originally developed for the CUSP NYU 2016-2017 Python Bootcamp and updated through 2020 for the SPPA667 Biden School of Public Policy and Administration class.

The course runs via **Google Colab**, so participants only need a browser-enabled device and an internet connection—no local package installation is required.

---

## Typical Syllabus

### Day 1
- What is a variable and native Python variables
- Lists and Strings: simple variable containers
- Arrays and Dictionaries: more complex variable containers
- Control Flow: `if`, `else`, and `elif` statements
- Loops
- Functions
- Reading in files and working with Pandas
- Simple math with Numpy
- Visualizing data with Matplotlib

### Day 2
- Slicing and Broadcasting: working effectively with Numpy
- PEP 8 and docstrings
- DataFrames manipulation: merges and pivot tables
- Classes and objects
- Scikit-learn (SKlearn) module and typical usage for machine learning models
- Maps with Python (if there is interest)

## Instructor Notes

> All the material is designed by me (taking much inspiration from a number of internet resources including [Software Carpentry](http://software-carpentry.org/), [Practice Python](http://www.practicepython.org/), and many more).

- The list of topics to cover is in `bootcampNB.md`; entries written in **bold** were not covered.
